SynapCores Community Edition

AI-native database. Open core. Self-hosted. Free.

The installer detects your platform, downloads the latest release from GitHub Releases, verifies its SHA-256 and sets up a service: a hardened systemd unit on Linux, a launchd agent on macOS. Press Enter at each prompt to accept the defaults. SynapCores prints your admin password the first time it starts; the steps below take you from install to signed in.

Install on Linux

  1. Install SynapCores. Option 1, the default, sets it up as a service that starts now and at every boot: 
    curl -fsSL https://get.synapcores.com/install.sh | sh
  2. Show your admin password and API key: 
    sudo journalctl -u synapcores --no-pager | grep -A9 "FIRST-BOOT CREDENTIALS"
  3. Open http://localhost:8080, sign in as admin and change the password.

Install on macOS (Apple Silicon)

  1. No Homebrew yet? Install it with the official command from brew.sh, then run the "Next steps" commands it prints: 
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  2. Install SynapCores. Enter your Mac password when asked, then press Enter at each prompt: the defaults install ffmpeg, tesseract and leptonica with Homebrew, then start SynapCores and print your admin password: 
    curl -fsSL https://get.synapcores.com/install.sh | sh
  3. Answered n to “Start SynapCores now?” Start it, now and at every login: 
    launchctl bootstrap "gui/$(id -u)" ~/Library/LaunchAgents/com.synapcores.gateway.plist
  4. Show your admin password and API key again (after a manual start, give it a few seconds): 
    grep -A9 "FIRST-BOOT CREDENTIALS" ~/.synapcores/logs/gateway.err.log
  5. Open http://localhost:8080, sign in as admin and change the password.

Install on Windows (WSL2)

  1. In PowerShell as administrator: 
    wsl --install -d Ubuntu
    On a first WSL install, restart Windows, then open Ubuntu from the Start menu and create your Linux user.
  2. In the Ubuntu terminal, follow the Linux steps above.
  3. Open http://localhost:8080 in your Windows browser. SynapCores runs while Ubuntu is open and starts again each time you open it.

Run with Docker (Linux and macOS)

docker run -d --name synapcores \
  -p 8080:8080 \
  -e AIDB_ACCEPT_LICENSE=1 \
  -v synapcores-data:/var/lib/synapcores \
  synapcores/community:latest

docker logs synapcores 2>&1 | grep -A9 "FIRST-BOOT CREDENTIALS"

The second command shows your admin password and API key; then open http://localhost:8080, sign in as admin and change the password.

Install the binary only (no system setup)

curl -fsSL https://get.synapcores.com/install.sh | SYNAPCORES_BINARY_ONLY=1 sh

Pin a specific release

curl -fsSL https://get.synapcores.com/install.sh | SYNAPCORES_VERSION=v1.0.0-ce sh
